and we have to use the scanner class...
import java.util.Scanner;

we have to use it at the top at the import section.

new -> works for dynamic memory allocation for new objects.

"S" of Scanner and System will be capital letter.

example for input:


      Scanner input = new Scanner(System.in);
      input.nextInt() // for int
      input.next() // just string / one word
      input.nextLine() // for complete string / full line
      input.nextDouble() // for double
      input.nextFloat() // for float
      input.nextLong() // for long
      input.nextBoolean() // for boolean

Scanner -> used for taking input from the user.

System.in -> takes input from keyboard.

Scanner input -> input is the object name.

new Scanner(System.in) -> creates a new Scanner object for taking input from keyboard. It 
can handle dynamic memory allocations of new objects as well.

next() -> takes only one word.

nextLine() -> takes the complete line/string.

example:

      String name = input.next();


if input is:

      Rahim Ahmed


then it will take only:


      Rahim

but,

      String name = input.nextLine();


will take:


      Rahim Ahmed


example:

      int age = input.nextInt();
      String name = input.next();
      String full_name = input.nextLine();
      double price = input.nextDouble();
      boolean check = input.nextBoolean();


important...!

if we use nextInt() and then nextLine():


      int age = input.nextInt();
      input.nextLine();
      String name = input.nextLine();


we have to use input.nextLine() after nextInt() because nextInt() leaves the Enter/newline behind.

at the end:

      input.close();


-> which closes the Scanner.

basic structure:

      import java.util.Scanner;

      public class Main {
          public static void main(String[] args) {

              Scanner input = new Scanner(System.in);

              // input

              input.close();
          }
      }

new -> small letter

nextLine() -> L is capital

character input:

      char ch = input.next().charAt(0);


-> next() takes one word/string as input.

-> charAt(0) takes the first character from that string.

-> 0 means the first character because indexing starts from 0.


example:

      char ch = input.next().charAt(0);


if input is:

      Rahim


then it will take:

      R


because R is the first character.


another example:


      char ch = input.next().charAt(0);


if input is:


      A


then it will take:


      A


another example:


      char ch = input.next().charAt(0);


if input is:


      hello


then it will take:


      h


because h is the first character.


important:

Java does not have ->  input.nextChar() for taking character input.

we use:

-->>    input.next().charAt(0)


next() -> takes the input as a String / one word

charAt(0) -> takes the first character from that String


example:


      String name = input.next();
      char ch = input.next().charAt(0);


if input is:

      Rahim A


then:

      name = "Rahim"

      ch = 'A'


character variable uses:


      char ch;


char values are written inside single quotation marks:


      'A'
      'a'
      '1'
      '@'


String values are written inside double quotation marks:

      "Rahim"
      "Ahmed"
      "Hello"


example:

      char ch = 'A';


but for taking character input from the user:

      char ch = input.next().charAt(0);
